## Что уже хорошо (не трогаем)
- Все операторские/админские роуты — под `preHandler:[authenticate]` (JWT verify). Покрытие сплошное.
- zod-валидация входных данных виджета (`visitorSessionSchema`, `messageSchema`, и т.д.) с `.max()`-лимитами.
- multipart `fileSize: 10MB` глобально.
- widget-бот вставляет `ai`-сообщения напрямую в БД на сервере (не через публичный endpoint).

## План закрытия (в этом треке)
- **F1 (High):** в widget-upload — проверять, что сессия существует и `status != 'closed'`; разрешать только image-mime (`image/*`); навесить rate-limit; auth НЕ добавляем (у визитора нет токена). → Task 7.
- **F2 (Medium):** caller-aware фикс online-роута (см. Task 6) — не сломать `sendBeacon` офлайна при закрытии.
- **F3 (Medium):** на публичном `messages`-endpoint форсировать `sender='visitor'` (после проверки, что виджет/бот не шлют `ai` через него); проверять, что сессия открыта. → Task 7.
- **F4 (Medium):** включить rate-limit на публичных widget-POST (создание сессии, сообщения, upload). → Task 7.
- **F5–F7 (Low):** бэклог трека A/далее: вынести срок JWT в env; сузить CORS; санитайз 500.
