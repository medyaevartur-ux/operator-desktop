## Что уже хорошо (не трогаем)
- Все операторские/админские роуты — под `preHandler:[authenticate]` (JWT verify). Покрытие сплошное.
- zod-валидация входных данных виджета (`visitorSessionSchema`, `messageSchema`, и т.д.) с `.max()`-лимитами.
- multipart `fileSize: 10MB` глобально.
- widget-бот вставляет `ai`-сообщения напрямую в БД на сервере (не через публичный endpoint).

## План закрытия — уточнён после проверки вызывающих (важно!)

Проверка реальных вызовов изменила подход к F2 и F3:

- **F1 (High) — серверный фикс, без пересборки приложения.** В widget-upload: проверять, что сессия
  существует и `status != 'closed'`; разрешать только `image/*` mime; навесить rate-limit.
  Auth НЕ добавляем (у визитора нет токена). Виджет грузит только картинки чата — не ломается.
- **F4 (Medium) — серверный фикс.** Включить rate-limit на публичных widget-POST (создание сессии,
  сообщения, upload) — заодно смягчает абуз из F1/F3.
- **F2 (Medium) — серверный фикс без правки клиента.** Установлено: `sendBeacon` шлёт ТОЛЬКО
  `{is_online:false}` (офлайн при закрытии/логауте, use-inbox.ts:74, auth.store.ts:88); «онлайн»
  ставится авторизованным `/status`. Решение: на `/online` разрешать `is_online:false` без auth
  (легитимный beacon), а `is_online:true` — требовать валидный JWT + совпадение оператора с `:id`.
  Закрывает спуф «сделать оператора онлайн». Полное закрытие forced-offline (токен в теле beacon)
  — отдельная мелкая правка клиента в 5.1.7. + rate-limit.
- **F3 (переоценка → Low, архитектурный бэклог, НЕ Track A).** Виджет ПО ДИЗАЙНУ постит `ai` и
  `system` через публичный endpoint (widget.js:2371, 2981, 1837, 2404 — AI-автоответы/системные с
  клиента). Форсировать `sender='visitor'` сломало бы виджет. Корректное закрытие — перенос генерации
  AI/system-сообщений на сервер (крупное изменение). Риск ограничен: только в своей сессии,
  UUID v4 неугадываем. Документируем как принятый риск.
- **F5–F7 (Low):** бэклог: вынести срок JWT в env (+рассмотреть refresh); сузить CORS для не-widget
  путей; санитайз 500-ответов.

**Деплоится в этом треке (серверно, без пересборки приложения):** F1, F4, F2(серверная часть).
**В 5.1.7 (правка клиента):** токен в теле beacon (полное закрытие F2 forced-offline).
**Бэклог:** F3 (архитектура), F5–F7.
