## Бэкенд (chat-api) — карта API уже реализованного
- Auth (JWT 30d), Sessions (assign/status/close/read/unread/priority/transfer/export/bulk close+assign/activity), Messages (CRUD/search/reactions), Operators (CRUD/avatar/status/online/heartbeat/activity/stats), Notes, Tags, Visitors (history/sessions/summary/start-chat), Settings, Auto-responses, Invitations (проактивные приглашения), Push (FCM), Upload (operator+widget), Widget (public), **Widget-bot** (кнопочные сценарии), Updater, Stats (overview), SLA (use-sla на клиенте).
- Realtime (socket.io /ws): join/leave session, typing, new_message, session_updated, new_session, operator_status_changed.

## Кандидаты в «Доработать»
- Composer-табы Email/SMS — заглушки → реализовать или скрыть.
- Шаблоны — переменные ({имя}, {оператор}), категории, вставка по `/`.
- Presence/текущая страница посетителя — точность + путь по сайту (Трек D).
- SLA — визуализация (таймеры первого ответа, индикаторы просрочки).
- Реакции/threads — единый MD3-вид.

## Кандидаты в «Новое» (предложения)
- **Дизайн-система MD3**: токены (цвет/типографика/elevation/motion/shape), тёмная/светлая темы, динамическая палитра от брендового цвета, единый набор иконок.
- Командная палитра 2.0 (действия + переход к диалогу + быстрые статусы).
- Сниппеты/AI-подсказки ответа в composer.
- Уведомления-«Ответить» прямо из тоста (частично запланировано).
- Дашборд аналитики (воронка, нагрузка операторов, время ответа).
- Назначаемость/маршрутизация (правила распределения чатов).
- Онбординг/пустые состояния, скелетоны, микроанимации.

## Жёсткие инварианты (не ломать)
- Поведения 1–4 (трей, маршрутизация по онлайну, разделение диалогов, presence).
- Widget-бот и ВК-бот, виджет на сайте.
- Апдейтер/выпуск (Трек A).
