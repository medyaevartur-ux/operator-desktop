# Работа над приложением оператора

Следовать текущему запросу пользователя и его общим правилам. Состояние этой разработки и границы разрешений записаны в `docs/HANDOFF-CODEX-2026-09-14.md`; входящий хендовер сохранён рядом без изменений.

- Развиваем Windows/Android-приложение, сервис `alphabet-chat-api` на `5.129.241.152` и `/var/www/widget/`. Изменения магазина, других сервисов, глобальной сети и настроек Windows не входят в эту работу.
- Согласованный дизайн: тёплый фирменный стиль «Живой Сказки». Целевой Android: Samsung S22 Ultra. Макет: `docs/design/v8.html`; он отделён от production-входа.
- Сохранять рабочие функции, пользовательские файлы и чужие изменения. Не запускать дополнительных агентов автоматически.
- Секреты не показывать. `src-tauri/gen/android/keystore.properties` локальный и игнорируется Git. Ключ подписи не заменять без отдельного решения о совместимости уже установленных приложений.
- Перед выкладкой виджета сверить live SHA256, проверить изменения и сохранить откат. Не менять магазинный `/api/upload`. Не перезапускать все процессы и сервер.
- Для изменений серверного исходника сначала подготовить baseline и безопасный выпуск: сейчас `/opt/alphabet-chat-api` не под Git. Не называть отправку JWT из клиента проверенной серверной авторизацией сокета.
- Не отправлять тестовые сообщения настоящим посетителям. Критические регрессии запускаются `npm run test:reliability`; `npm run build` проверяет типы и собирает интерфейс. Нативную доставку подтверждать только на реальном устройстве.
- При ограничении памяти собирать Rust с `CARGO_BUILD_JOBS=1`. Не останавливать чужие процессы и не менять файл подкачки автоматически.
- Обновлять существующий рабочий хендовер результатами: выполнено, проверено, не проверено, следующий шаг. Не создавать дубликаты для каждой итерации. Личную память менять только по прямой просьбе.
